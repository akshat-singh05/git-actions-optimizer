# Calibration of the failure probabilities

Generated by `gha-optimizer eval-calibration`. Method: `gha_optimizer/models/calibration.py`. Rolling-origin folds as in `eval-models`; pooled out-of-sample predictions; paired cluster bootstrap over runs (1000 resamples). Arms: **raw** = the default failure model's score; **platt_tail** = a sigmoid fitted on the newest 25% of the training rows; **isotonic_oos** = an increasing map from score to the failure rate observed on the *earlier folds'* out-of-sample predictions (it learns only from the past); **baseline** = the job's prior failure rate. All arms are scored on the same rows (the first fold has no earlier out-of-sample evidence and is left out).

**Brier score, log-loss and ECE (expected calibration error, 10 equal-mass bins): lower is better; ECE 0 means a predicted 30% fails 30% of the time.** The calibrators are increasing maps, so ranking metrics are not worse than the raw model's (isotonic can create ties).

A score above the highest one the model ever produced on unseen rows is an extrapolation: no out-of-sample evidence says how often such a job fails. The dashboard flags such scores and shows the observed failure rate of unseen rows that scored alike next to the raw score, the job's own base rate and the baseline.
