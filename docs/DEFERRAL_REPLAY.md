# Counterfactual replay: defer the graph-unreached jobs on pull_request runs

Generated by `gha-optimizer replay-impact --deferral` from the database (**MEASURED on history**; the policy was not run). Cluster bootstrap over PR runs (1000 resamples, seed 13). Definitions, criteria and what is NOT measured were fixed before any figure was computed: `docs/DEFERRAL_PLAN.md`.

Policy: on `pull_request` runs, do not run the jobs the readable DAG-safe policy would skip; they still run on `push` runs. Savings can only come from PR runs. A failure of a deferred job is **pre-existing** if the same job also failed in the push run on the default branch at the PR's base commit, **new** if it ran and passed there, **unknown** if no such run / job exists. **Whether a hidden failure recurs after merge is not measured** (the database cannot link a PR to its merge commit).
